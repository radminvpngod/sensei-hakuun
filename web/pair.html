Connect your phone

Waiting for your phone…
  1. Phone on the same Wi-Fi as this PC. Scan the code with your camera.
  2. Your phone will warn that the connection isn't private: that's Sensei's own certificate on your home network. Tap Show details → visit this website (iPhone) or Advanced → Proceed (Android).
  3. Tap Start pointer and allow motion access. Hold the phone flat, top edge toward the screen, like a Wii remote.
  4. If Windows asks about the firewall, allow Private networks.
The link contains a private key: only phones you show this code to can control your PC.
