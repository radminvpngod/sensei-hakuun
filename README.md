# Sensei Hakuun 白雲

A ghost-koi sensei for your Windows desktop, plus a walkable zen garden.

- `web/` — the UI the app downloads on start (overlay, launcher, pairing, phone remote). Bump `web/manifest.json` → `version` to push an update to every install.
- `app/` — the small Electron shell (windows, tray, hotkeys, game scanning, phone-remote server, mouse control).

Hotkeys: `Ctrl+Shift+Space` launcher · `Ctrl+Shift+H` hide/show Sensei · `Ctrl+Shift+G` garden.
